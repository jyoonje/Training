## 쓰레드
정의: 프로세스에서 리소스의 제어를 담당하는 프로세스 실행 단위

### 제어 정보
- 프로세스: SP(Stack Pointer), PC(Program Counter), 지역 변수, 스택 -> 쓰레드가 처리
- 리소스: 소스 코드, 전역 변수, 힙 -> 공유되는 자원

같은 프로세스의 쓰레드들은 동일한 주소 공간을 보유하며, 각각의 쓰레드는 각각의 소스 코드를 가리키는 PC를 갖는다.

### 쓰레드의 구성 요소
- Thread ID
- Register Set(PC, SP 등)
- Stack(지역 변수)

제어 요소 외 코드, 데이터 및 자원들은 프로세스 내 다른 쓰레드들과 공유
전통적 프로세스 = 단일 쓰레드 프로세

### 쓰레드의 장점
- 사용자 응답성
  - 일부 쓰레드의 처리가 지연되어도 다른 쓰레드는 작업을 계속 처리 가능
- 자원 공유
  - 효율성 증가
    - 여러개의 프로세스가 자원을 공유할 시 커널이 매 순간 개입하여 context switch가 발생
    - 멀티 쓰레드 프로세스는 여러개의 쓰레드가 자원을 공유해도 context switch가 발생하지 않음
- 경제성
  - 프로세스의 생성, context switch에 비해 효율적
- 멀티 프로세서(CPU) 활용
  - 병렬 처리를 통해 성능 향상
