### 클라이언트 사이드 자바스크립트 타임라인
#### 브라우저가 HTML과 JavaScript를 어떻게 처리하는가

- 자바스크립트 프로그램은 스크립트 실행단계 -> 이벤트 처리 단계로 넘어간다.
두 단계는 다음과 같이 여러 단계로 쪼갤 수 있다.

1. 웹 브라우저가 Document 객체를 생성하고 웹 페이지 분석을 시작ㄱ한다.
HTML 요소와 텍스트 컨텐츠를 분석할 때마다 Element 객체와 Text 노드를 문서에 추가한다. 이 단계에서 document.readyState 프로퍼티의 ㄱ ㅏㅄ은 loading이다.

2. HTML 파서가 async, defer, tupe="module" 속성이 없는 <script>태그를 만나면 슼크립트 태그를 문서에 추가하고 스크립트를 실행한다.
스크립트는 동기적으로 실행, HTML파서는 스크립트를 ㄴ ㅐ려받아 실행하는 동안 일시 중지된다. 
이런 스크립트는 나중에 사용할 이벤트 핸들러를 등록하김만 ㅎ ㅏ는 경우가 대부분이지만, 이 시점에는 자신이 존재하는 것처럼 문서 트리를 이동하고 조작할 수 있다.
   asyncc나 defer 속성이 없는 비모듈 스크립트는 자기 자신의 <script>태그와 그 앞에 있는 문서 콘텐츠를 볼 수 잇다

3. 파서가 async 속성이 있는 스크립트 요소를 만나면 스크립트 텍스트를 내려받으며,  스크립트가 모듈이라면 가져오는 모듈 역시 재귀적으로 내려받아 분석을 계속한다.
   파서는 내려받기가 끝나기를 기다리지 않는다. 비동기 스크립트는 자신의 <script>태그와 그 앞의 문서 콘텐츠를 볼 수 있고, 나머지 콘텐츠는 볼 수 있을수도, 없을 수도 있다.

4. 문서 분석이 완전히 끝나면 document.readyState 프로퍼티가 interactive로 바뀐다.

5. defer 속성이 있는 스크립트, async 속성이 없는 모듈 스크립트는 문서 순서대로 실행된다. 비동기 스크립트도 이 때 실행될 수 있다.
지연된 스크립트는 문서 전체에 접근할 수 있다.

6. 브라우저가 Document 객체에서 DOMContentLoaded ㅇ ㅣ벤트를 일으킨다. ㅇ ㅣ 이벤트는 스크립트 단계를 두 번째 단계로 전환한ㄴ다. 이 시점에 아직 실행되지 않은 async 스크립트가 있을 수도 있다.

7. 이 시점에서 문서 분석은 완전히 끝났지만 브라우저는 여전히 이미지같은 콘텐츠를 기다리고 있을 수 있다. document.readyState 프로퍼티는 complete로 바뀌고 웹 브라우저는 Window 객체에서 load 이벤트를 일으킨다.

8. 이제부터 사용자의 입력 이벤트, 네트워크 이벤트, 타이머 종료 등에 의해 이벤트 핸들러가 비동기적으로 호출된다.

위 단계들을 요약하면 ㄷ ㅏ음과 같다.

```
HTML 다운로드
    ↓
HTML 파싱
    ↓
DOM 생성
    ↓
<script> 처리 및 async 처리 시작(async는 언제 실행ㄷ될지 모름)
    ↓
DOM 생성 완료
    ↓
document.readyState = interactive
    ↓
defer / module 실행
    ↓
DOMContentLoaded
    ↓
이미지 등 리소스 로딩 완료
    ↓
document.readyState = complete
    ↓
load
    ↓
사용자 이벤트 / 네트워크 / 타이머 ...
```

### 프로그램 입출력
클라이언트 사이드 js 프로ㅗ그램도 입력 데이터를 처리해 출력 데이터를 만든다. 사용할 수 있는 입력 형태는 다양하다.

- js 코드에서 DOM API를 통해 접근할 수 ㅇ ㅣㅆ는 문서 콘텐츠 자체
- 이벤트 형태인 사용자 입력
- HTTP 쿠키 요청 헤더 콘텐츠는 document.cookie로 사용할 수 있다.
- 전역 navigator 프로퍼티를 통해 웹 브라우저, 운영 체제와 그 기능에 접근할 수 있다. 마찬가지로 전역 screen 프로퍼티를 통해 사용자의 디스플레이 크기에 접근할 수 있다.
```
navigator: document와 비슷하게 브라우저가 제공하는 전역 객체이지만, DOM 객체는 아니다. 현재 브라우저/실행 환경 정보
ex) navigator.userAgent, navigator.language ...
```

클라이언트 사이드 자바스크립트는 DOM API 또는 리액트, 앵귤러 같은 프레임워크를 통해 HTML 문서를 조작한다. 클라이언트 사이드 코드는 console.log나 관련 메서드를 통해 출력할 수 있다.
